# meowbin
generic pastebin slop written in typescript with bun+elysia

## branches
* main - tested and working as intended version
* master - completely untested, probably just pseudocode written on a school chromebook (rebased later onto main)

## planned features
* plain text/markdown
* proper editor support (likely implementing options or something lightweight)
* super config-dense
* pastes encrypted server-side
* paste options (expiry, password protect on top of encryption, etc)
