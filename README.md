# meowbin

generic pastebin slop written in typescript with bun+elysia

## branches

- main - tested and working as intended version
- unstable - completely untested, probably just pseudocode written on a school chromebook (rebased later onto main)
  - apparently, google drive is absolutely terrible as a vcs so i lose most of the code anyways. thanks for bumping the last modified time and not the contents

## planned features

- plain text/markdown
- proper editor support (likely implementing options or something lightweight)
- super config-dense
- pastes encrypted server-side
- paste options (expiry, password protect on top of encryption, etc)
- maybe decoupling frontend/backend so api can be standalone
